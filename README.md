# AV Silencer
Chrome Extension that mutes AV whenever he starts talking, playing music in the background with announcements. 

To install it you need to:

1. Unpack the .zip file.
2. Open Chrome > Manage Extensions
3. Turn ON Developer Mode in the top right corner
4. Click on the "Load unpacked", then select the unpacked folder.
5. Make extension pinned to toolbar (there is a slider in Manage Extensions on that specific extension).
6. Reload Chrome and Youtube chrome tab where AV is speaking.
7. Click on tab where AV is speaking to focus it.
8. Click on Extension icon in the toolbar (its next to the URL field) and click Start.
